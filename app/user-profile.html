📅 Calendar Sync

Subscribe to a live read-only feed of all your booked gigs. New bookings appear automatically; cancellations remove the event.

✓ Safe to share publicly. The feed includes venue name, address, date, slot times, and the booked artist — perfect for embedding on a band's website, a venue's show calendar, or a tour-dates page. Pay terms are intentionally NOT included, so you can publish the URL without leaking deal info.

The URL still contains a private token — anyone with it can see your booking schedule. If you ever want to invalidate a shared URL (e.g. parted ways with a band member), hit Rotate below.

How to subscribe
  • Google Calendar → Settings → Add calendar → From URL → paste the URL above.
  • Apple Calendar → File → New Calendar Subscription → paste the URL.
  • Outlook → Add calendar → Subscribe from web → paste the URL.
