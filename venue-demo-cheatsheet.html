GigsFill — Venue Demo Cheat Sheet

Check off as you go · ~20 min full flow

1Sign Up & Venue Setup

  • Create account (email, name, phone)
  • Add venue — name, address, capacity
  • Logo + hero photo + bio
  • Amenities — stage, sound, engineer, lighting
  • Add Stripe card on file
  • Invite secondary users (staff)
  • Set venue timezone

2Create a Gig

  • Date + times, single or multi-slot
  • Artist Type per slot (6 options incl. MC)
  • Live Band → pick Lineup + Styles
  • MC types → "requires own equipment" filter
  • Flat pay OR Door deal (guarantee + %)
  • Flyer canvas editor (layers, text, images)
  • Recurring weekly / biweekly / monthly
  • Hold gig — offer to preferred first

3Find & Manage Artists

  • Search Artists — name / city / radius / type
  • Type venue/city → pills auto-populate
  • Preferred Artists — priority + freq limits
  • Per-artist Pay Override (auto-applied)
  • Per-artist Frequency Days gap
  • Ban artist — permanent block
  • Waitlist — queue for recurring gigs

4Email Notifications

  • Gig Confirmation reminder (1w before)
  • Open-gig blasts at 4w / 2w / 1w / 36h
  • Waive Frequency per-row toggle
  • Send to ALL within X mi — non-preferred blast
  • Cancellation blast auto when gig re-opens
  • Smallest-window rule → picks right settings
  • Blink calendar bubble after fire
  • Full template library — editable

5Booking & Contracts

  • Artist books → auto PDF contract
  • Artist signs → venue countersigns
  • Message Artist from calendar
  • Activity Center — one feed for all events
  • .ics invite for venue's calendar
  • Status: Pending → Countersign → Booked

6Payments & Payouts

  • Card charged day-after at 5 PM local
  • Artists paid via Stripe Connect Express
  • Door deal auto-settles from receipts
  • Door Receipts button closes 5 PM day-after
  • Platform fee 50/50 venue & artist
  • Payments tab — every txn + status
  • Cancel/reinstate before payout fires
  • Free-trial mode (payments suspended)

7Calendar & Public Face

  • Monthly calendar, color-coded status
  • Hover cards — full details, no click
  • Public Gigs browse (non-logged-in)
  • Venue Discovery — artists find you
  • Blinking bubble when blast is live
  • Public venue profile — bio + shows

8Post-Gig

  • Rate Artist (1–5 + comments)
  • Reviews on artist's public profile
  • Cancel slot pre-payout → pro-rata refund
  • Add Door Receipts → Stripe queue
  • Support ticket → GigsFill mediates disputes
  • Historical reports — earnings, bookings

9Artist Side (impacts you)

  • Profile: type, lineup, styles, gear, radius, blackouts
  • Search Gigs auto-defaults to profile; auto-applies filters
  • Books → contract fires → both sign, no phone tag
  • Multi-artist users — one account, 2+ projects
  • Frequency limits enforce your booking cadence
  • Waitlist for recurring/popular gigs
  • Blackout dates auto-excluded from your blasts
  • iCal export + auto reminder emails
💡 Talking points: lead with time saved (auto-payout, auto-contracts, auto-blast) and risk reduction (frequency limits, blackouts, contracts, dispute mediation). Free-trial toggle lets them try before adding a card. Show the calendar early — it's the "wow" moment.
